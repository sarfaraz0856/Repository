# Smart Learning Hindi — standing notes for Claude

## Title / thumbnail / description / tags language
- Choose the language per element by what matches search best — don't default to one.
- Default to Hinglish (Roman Hindi + English mix, e.g. "Mobile Se YouTube Channel Kaise Banaye 2026"), since viewers search that way.
- Use plain English where English terms are what people actually type (e.g. "AdSense", "Step by Step", "Full Guide", chapter names).
- Use Devanagari only if it clearly fits the topic's search better.
- Thumbnail text: short, big, Hinglish/English mix — whatever reads fastest.

## Upload kit
- Keep file names short and keyword-based (main search phrase only), e.g. `youtube-channel-kaise-banaye.mp4`, `...-A.png`, `...-hindi.srt`, `title-description-tags.txt`.
- Give 3 thumbnails (A/B/C) with matching titles for "Test & Compare", Hindi + English SRTs, chapters in the description.
- Descriptions should sound human: few or no emojis, no em dashes, first person.

## Rules
- Never commit voice recordings or MP3s.
- Analyses are delivered as an A4 PDF.
