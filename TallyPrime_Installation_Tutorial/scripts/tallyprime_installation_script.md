## ⚠️ ACCURACY NOTICE — READ BEFORE RECORDING

This script is written from **verified official sources** (tallysolutions.com download page and help.tallysolutions.com install guide) as of **19 October 2026**. A few details change with every TallyPrime release, so the following items are marked **[VERIFY LIVE]** — you MUST confirm them on the official page on the day you record, and say the correct number on camera. Do NOT read a guessed value.

| Item | Status | What to do |
|---|---|---|
| Exact current version number (e.g. "7.x") | **[VERIFY LIVE]** | Read it off `tallysolutions.com/download` on recording day |
| Installer file name & download size | **[VERIFY LIVE]** | Note the real file name/size shown in your browser |
| SHA-256 checksum value | **[VERIFY LIVE]** | Copy the hash shown on the official download page |
| Exact RAM/disk minimums for your version | **[VERIFY LIVE]** | Official pages have ranged from 512 MB to 4 GB across versions — quote the page for your version |
| Educational Mode voucher-date rule | **[VERIFY LIVE]** | Commonly 1st / 2nd / 31st, but confirm for your version |
| License edition prices (Silver/Gold) | **[VERIFY LIVE / OPTIONAL]** | Prices change; either skip or quote the live page |

**Verified facts you CAN state confidently:**
- TallyPrime runs on **Windows only** (Windows 7 and above, 64-bit).
- Official download source is **tallysolutions.com/download** only.
- Installation needs **administrator rights** on the PC.
- Official flow: run **setup.exe → Install New → (optionally change Application Path) → Install → Start TallyPrime**. Default path: `C:\Program Files\TallyPrime`.
- Tally officially recommends **verifying the SHA-256 checksum** of the downloaded setup file.
- **Educational Mode** is a free, unlicensed way to learn Tally with date restrictions; it is NOT a way to bypass payment, and installing Tally is NOT the same as activating a license.

## SCENE 6 — VERIFY THE INSTALLER
**Duration:** ~1:15

**Narration:**
"Ye step security ke liye hai. Tally officially recommend karta hai ki aap downloaded setup file ka **SHA-256 checksum** verify karein — matlab ye confirm karein ki file download ke dauraan change ya corrupt nahi hui. Iske liye official download page par ek checksum value di hoti hai [VERIFY LIVE]. Apne PC par Windows PowerShell kholiye, aur command chalaiye: `Get-FileHash -Algorithm SHA256 "file ka path"`. Jo value aaye, use official value se match kariye — agar dono same hain, file safe hai. Aap file par right-click → Properties → 'Digital Signatures' tab se publisher 'Tally Solutions' bhi dekh sakte hain. Agar aap verify nahi kar paate, kam se kam ye yaad rakhein ki file sirf official site se aayi honi chahiye."

**On screen:** PowerShell with the `Get-FileHash` command and output → file Properties → Digital Signatures tab.
**Actions:**
- Open PowerShell.
- Run `Get-FileHash -Algorithm SHA256 "<path to setup file>"`.
- Compare with the official hash.
- Optionally: right-click file → Properties → Digital Signatures → show publisher.
**Viewer should understand:** Why official-only matters; how to verify integrity/publisher.
