# Typing series video toolkit

Source for the "Fast Typing Course in Hindi" videos (Part 3: Typing Test / 50 WPM).
Media, model weights and rendered videos are not stored here.

- `animation/` — Remotion scenes (keyboard + hands engine in `kb.tsx`, Part 3 scene in `p3.tsx`).
  Needs `remotion@4.0.539`, `react@18.3.1`; `src/p3timing.json` is generated by `part3/build_timing_p3.py`.
- `voice/` — cloned-voice pipeline:
  `clean.py` (denoise the speaker sample) → `tts_p3.py` (Kokoro Hindi TTS, `hm_omega`) →
  `myvc.py` (kNN-VC style conversion: WavLM-Large via `transformers` + HiFi-GAN, weights from
  github.com/bshall/knn-vc releases, loaded with `weights_only=True`) → `assemble_vo.py`
  (joins lines, writes word timings).
- `part3/` — timing, key-press sounds, final mix (1.1x speed) and subtitles (Hindi / Hindi-Latin / English).
