# YouTube Channel Tutorial — Production Kit (2026)

Topic: **"How to Create a YouTube Channel Using Your Mobile Phone — Step by Step (Hindi/Hinglish, 2026)"**
Target: a 12:00, 1920×1080, 30fps, MP4/H.264 + AAC educational tutorial.

## Contents
- **YouTube-Channel-Tutorial-Production-Kit.pdf** — the main A4 deliverable. Full timed Hindi/Hinglish
  voice-over script (14 segments to 12:00), on-screen captions, shot-by-shot screen-recording plan,
  thumbnail/banner/logo specs, channel name/handle/description, SEO metadata, export settings,
  and verified-facts/sources page.
- **assets/thumbnail.png** — 1280×720 thumbnail (ready to upload).
- **assets/banner.png** — 2560×1440 channel banner, text inside the 1546×423 safe area.
- **assets/logo.png** — 800×800 profile picture / logo ("SL" monogram).
- **assets/*.html** — editable source for each image asset.
- **production-kit.html** — editable source for the PDF.

## How to produce the video
1. Record the voice-over (read the red boxes in the PDF, or use an Indian Hindi TTS / your own voice).
2. Screen-record each step on a real Android phone (green shot lists) using a demo Google account.
3. Edit in CapCut / VN / KineMaster / DaVinci Resolve: voice-over first, screen clips under it,
   captions + zoom-ins + highlights per the notes.
4. Export with the settings on the last PDF page; upload with the supplied title/description/tags.

## Notes
- Example channel "Smart Learning Hindi / @SmartLearningHindi" is fictional (demo only).
- Always record the real, current YouTube app flow — never animate invented buttons.
- No full AI-generated video: AI video can't reproduce the real YouTube mobile UI accurately,
  which would break the "do not invent buttons" / accuracy requirement.
